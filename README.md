# Q&A Notes

This branch contains notes from our discussions in a simple **Question & Answer format**.

## Purpose

The goal is to save important questions, answers, explanations, and key points in one place so they can be easily reviewed later.

## Format

Each topic will follow this structure:

### Question

What was discussed or asked?

### Answer

A clear and simple explanation of the answer.

### Key Notes

* Important points
* Things to remember
* Examples, if needed

## Goal

These notes are mainly for:

* Quick revision
* Better understanding
* Future reference
* Keeping track of learned topics
